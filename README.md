# Python Student Result System
A beginner Python projects that collects students' subjects and scores, calculates their total scores and determines their academic results.
## Features
Collects the names of a student.
Collects the number of subjects offered by a student.
Collects the names of the subjects.
Collects scores for each subject.
Calculates the total and average scores.
Displays the student's academic results

For loops.
